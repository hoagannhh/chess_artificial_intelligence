# Thực nghiệm AI

Chưa có kết quả đo. Sau khi có AI, lưu tập thế cờ và cấu hình cùng kết quả CSV.

Các trường dự kiến: position_id, algorithm, depth, time_limit_ms, elapsed_ms, nodes, score, best_move.

Ghi phiên bản code, phần cứng và điều kiện chạy. So sánh cùng thế cờ và độ sâu; không suy ra Elo từ vài ván tự đấu.
