# Tài nguyên

Bộ ảnh game hiện tại nằm trong `scifi/`: robot hai phe và nền trạm không gian, tạo bằng ImageGen theo ảnh tham chiếu người dùng chọn. Xem `scifi/README.md` cho bố cục atlas và nguồn.

Bàn cờ, khung kim loại, ánh sáng viền và UI được vẽ bằng Pygame. Font dùng Segoe UI trên Windows, có fallback.
